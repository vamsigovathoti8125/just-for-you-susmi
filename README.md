# Just for you, Susmi

A personalized, static letter experience with six envelopes, a video, background music, and a final proposal.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static web server. Keep the `music` folder beside `index.html`; it contains the photos, video, and music used by the page.

Enter **Susmi** to view the gift. Enter **Vamsi** on the opening screen to access the editor and saved responses.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. GitHub Pages will publish `index.html` and the files in `music`.

Gift edits and proposal responses are stored in the browser's local storage. They do not sync to other devices.
